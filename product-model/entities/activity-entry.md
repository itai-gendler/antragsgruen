# Activity entry

Activity entry information kept by Antragsgrün.

## Information kept

- **Operation** — Visible consultation operation.
- **Actor** — Who initiated the operation.
- **Target** — Operation subject.
- **Time** — Operation time.
- **Details** — Disclosed operation details.
