# Agenda item

Agenda item information kept by Antragsgrün.

## Information kept

- **Code** — Agenda code.
- **Title** — Item title.
- **Hierarchy** — Parent and order within the agenda.
- **Timing** — Configured date and time.
- **Procedure inclusion** — Whether included in procedure.
- **Associated type** — Associated Motion type.
- **Speaking resources** — Associated speaking list.
