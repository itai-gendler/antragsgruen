# Section definition

Section definition information kept by Antragsgrün.

## Information kept

- **Section identity** — The addressed definition used by document sections.
- **Kind** — The kind of section.
- **Title** — Section title.
- **Order** — Order within the type.
- **Languages** — Configured content languages.
- **Requirements** — Required contents and constraints.
- **Publicity** — Disclosure configuration.
- **Editability** — Editing configuration.
- **Removed** — Whether the definition has been removed.
